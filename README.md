# youziauth：西南大学校园网自动认证工具

youziauth 是一款面向西南大学校园网 ePortal 环境的 Windows 自动认证工具。完成一次配置后，它可以在电脑开机时自动检查网络并进行认证，同时提供系统托盘、失败重试和本地凭据保护。

> [!IMPORTANT]
> 本项目由个人开发，是非官方开源工具，与西南大学及校园网运营商无隶属、授权或合作关系。

## 功能特点

- 统一桌面工作台：今日概览、校园网、寝室打卡、运行记录在同一窗口切换；

- 开机后自动检查并认证校园网；
- 已经能够正常访问互联网时自动跳过认证；
- 支持账号、密码和检测间隔设置；
- 支持系统托盘和后台持续检测；
- 认证失败时提供“重新认证”和“打开设置”通知；
- 安装版使用 Windows DPAPI 在本机保护密码；
- 不包含遥测或第三方数据收集功能。
- 寝室打卡：独立学校登录、今日任务查询、实时定位、提交后回查和可选自动执行。

## 寝室打卡（集成预览）

在统一主窗口左侧点击 **寝室打卡**，或从托盘菜单打开 **寝室打卡**。托盘入口会切换到同一个窗口里的打卡页面。

1. 点击 **登录 / 重新登录**，在打开的 Chrome（未安装时使用 Edge）窗口中完成学校统一身份认证。使用独立临时浏览器会话，自动经过学校认证中转页；校园网认证和打卡登录态分别管理，软件不保存统一认证密码。
2. 点击 **查询今日任务**，检查任务日期、地点和学校时段。查询不会提交打卡。
3. 点击 **授权并检测定位**。如果 Windows 弹出权限提示，选择允许；已拒绝的权限需要通过 **Windows 定位设置** 重新开启。检测只检查本机实时位置与精度，不提交打卡，也不展示经纬度。成功后查询今日任务，再点击 **提交今日打卡**；提交时会重新获取实时位置，经学校定位校验后提交，并回查服务器结果。
4. 需要自动执行时，勾选 **启用自动打卡**，设置检查时段和间隔，点击 **保存打卡设置**。默认关闭；默认检查时段为北京时间 21:00–23:30，每 300 秒检查一次，提交仍以学校当天任务时段为准。

运行条件与限制：

- 需电脑开机、用户登录 Windows、软件保持运行；关闭打卡设置窗口后仍可后台执行。退出整个软件会停止打卡，睡眠期间不运行，恢复后在有效时段内补查。已有“开机自启动”设置会在用户登录时启动托盘及打卡调度。
- 登录 Token 有效时复用，失效时通知重新登录，不自动弹浏览器、不尝试 OCR。登录需要已安装的 Edge 或 Chrome。
- 每次提交使用 Windows 位置服务数据，拒绝超过 120 秒或误差超过 200 米的定位。Windows 可能无法提供足够准确的位置；不会以校园网在线状态或历史宿舍坐标代替实时定位。
- 1.3.1 起使用 Windows WinRT 定位接口，最多等待约 30 秒取得实时数据，分别提示权限拒绝、服务关闭、无信号、超时、过期或精度不足。默认位置及 IP 粗略位置不用于打卡；授权成功不等于定位一定可用。
- Windows 的 WGS84 坐标转换为表单使用的偏移坐标；学校接口兼容性和定位接受情况尚需真实账号验证。若位置校验不通过，请在学校官方页面处理。
- 同一天存在多条无法唯一确定的任务、字段不完整或任务已过期时停止提交。不支持跨日任务。
- 提交超时或回查无法确认时显示 **提交结果待确认**，后续仅回查，不重复提交；请在学校页面核实并必要时在那里完成。
- 网络代理和打卡工作线程独立，停止校园网后台检测不会关闭打卡；关闭打卡请在打卡设置中取消勾选并保存。取消当前操作不会关闭自动设置；已发出的提交不能撤回。

打卡数据存放在 `%LOCALAPPDATA%\youziauth\dorm`：Token 使用当前用户范围 DPAPI 单独加密；设置、任务状态与精简历史记录仅保存本机。**清除登录凭据** 同时关闭自动打卡。打卡会向 `of.swu.edu.cn` 发送登录 Token、任务字段及实时位置；登录浏览器访问学校认证站点，Windows 定位由系统服务提供。不要分享该目录。

从源码运行时，先执行 `python -m pip install -r requirements-dorm.txt`。打包执行 `./build_msi.ps1 -InstallDependencies`，登录组件随包分发，不包含浏览器本体。

本次集成以本地 `swu-daka` 提交 `42d8973` 的接口流程为参考；自动化测试使用模拟学校响应，并不代表真实账号已成功打卡。

## 使用要求

- Windows 10 或 Windows 11；
- Microsoft Edge WebView2 Runtime（新版桌面界面需要；仅安装普通 Edge 浏览器不等同于已安装 Runtime）；
- 已连接西南大学校园网；
- 拥有可正常使用的校园网账号；
- 安装和启用开机自启动时可以接受 Windows 管理员授权提示。

普通用户安装 MSI 后不需要另行安装 Python。

## 下载与安装

1. 打开本仓库右侧的 **Releases** 页面；
2. 进入最新版本，下载 `youziauth.msi`；
3. 双击安装包并按照提示完成安装；
4. 从 Windows 开始菜单启动 **youziauth**。

安装过程中如果 Windows 显示安全确认，请先核对文件来源和 Release 页面提供的 SHA-256，再决定是否继续。

## 首次使用

1. 确保电脑已经连接西南大学校园网；
2. 在左侧进入 **校园网**，填写校园网账号；
3. 在“密码”中填写校园网密码；
4. “检测间隔（秒）”建议保留默认值 `60`；
5. 点击 **保存设置**；
6. 点击 **立即检测**，确认连接状态；
7. 如果希望开机自动认证，勾选 **开机自启动**，然后再次保存。

启用或关闭开机自启动时，Windows 会请求管理员授权。这是因为程序需要创建或移除开机认证任务。

## 日常使用

关闭主窗口不会退出程序，而是把它隐藏到系统托盘；托盘不可用时会最小化到任务栏。已运行的后台任务继续执行，关闭窗口本身不会开启新的检测任务。托盘图标会显示当前状态，例如在线、离线、检测中、已停止或错误。

右键单击托盘图标可以：

- 查看当前状态；
- 显示主界面；
- 进入设置；
- 立即检测；
- 退出程序。

如果重复启动 youziauth，程序会提示当前电脑已经在运行。此时请在系统托盘中打开已有实例。

## 设置说明

| 设置项 | 说明 |
|---|---|
| 账号 | 西南大学校园网账号 |
| 密码 | 校园网密码；安装版使用 Windows DPAPI 在本机保护 |
| 检测间隔（秒） | 后台认证成功后的常规检查间隔，建议使用默认值 60 |
| 开机自启动 | 开机时启动系统认证代理，登录 Windows 后启动托盘程序 |

左侧 **运行记录** 可在校园网和寝室打卡记录间切换，点击 **刷新记录** 可重新读取。校园网设置有未保存修改时，先保存再检测；停止后台检测不受未保存设置影响。

## 新界面预览与源码运行

双击仓库中的 `start_desktop_preview.vbs` 可打开独立桌面演示窗口。演示只使用内存数据，不读取真实账号、不打开学校登录、不获取位置，也不提交打卡。

源码运行新版界面前安装依赖：

```powershell
python -m pip install -r requirements-desktop.txt -r requirements-dorm.txt
python campus_auth_gui.py
```

`python campus_auth_desktop.py --preview` 启动桌面演示；`python campus_auth_desktop.py --preview-server --port 8766` 启动仅绑定本机的浏览器演示，访问 `http://127.0.0.1:8766/?preview=1`。浏览器演示没有真实后台功能。

旧 Tkinter 界面保留为排障入口：`python campus_auth_gui.py --legacy-ui`。界面资源、字体图标和纸纹随安装包分发，断网也能打开界面。学校登录与校园网认证仍需要相应网络服务。

## 常见问题

### 点击“检测一次”后认证失败

请依次确认：

1. 当前连接的是西南大学校园网，而不是普通宽带或手机热点；
2. 校园网账号和密码可以在学校认证页面正常登录；
3. 账号没有欠费、停机、达到设备数量限制或被临时锁定；
4. 重新填写密码并保存，然后再次点击 **检测一次**；
5. 查看窗口中的状态和日志，确认服务端返回的具体提示。

如果校园网认证页面或协议发生变化，旧版本可能暂时无法使用。请查看 Releases 中是否有更新版本。

### 提示服务类型错误

从源码运行时，可以把配置文件中的 `service` 留空后重试：

```ini
service =
```

安装版没有暴露该高级选项。如果持续出现此错误，可以先使用学校网页认证，并关注后续版本。

### 开机后没有自动认证

- 打开设置，确认 **开机自启动** 已勾选并保存；
- 如果保存时出现管理员授权窗口，请选择允许；
- 在主界面点击 **检测一次**，先确认账号本身能够认证；
- 如果使用手机热点或其他已经可以上网的连接，程序会主动跳过校园网认证。

### 关闭窗口后找不到程序

主窗口关闭后会隐藏到系统托盘。点击任务栏右侧的托盘展开按钮，找到 youziauth 图标，然后右键选择 **显示主界面**。

### 收到“校园网认证失败”通知

通知中可以选择：

- **重新认证**：立即重新尝试；
- **打开设置**：检查账号、密码和日志；
- **本次不再提醒**：在本次 Windows 启动期间停止重复提醒。

下次重新启动 Windows 后，提醒抑制会自动重置。

## 安全与隐私

youziauth 不包含遥测或第三方数据收集功能。校园网认证时，账号和密码只会发送到配置的校园网认证地址。可选寝室打卡功能的数据发送范围见上文“寝室打卡”。

安装版将配置和 DPAPI 凭据保存在：

```text
%ProgramData%\youziauth\config.ini
%ProgramData%\youziauth\credential.dat
```

密码不会以明文形式写入安装版的 INI 文件。DPAPI 凭据只能在相应 Windows 环境中解密，但仍不应复制或分享给他人。

向他人寻求帮助前，请隐藏或删除以下内容：

- 校园网账号和密码；
- 完整登录地址及其查询参数；
- MAC 地址、设备 IP 和其他网络标识；
- 未经处理的配置文件、凭据文件、日志和截图。

安全问题报告说明见 [SECURITY.md](SECURITY.md)。

### 环境要求

- Windows 10 或 Windows 11；

Copy-Item .\config.example.ini .\config.ini

编辑 `config.ini`，填写账号并保持 `password` 为空。推荐只在当前 PowerShell 会话中设置密码：

```powershell
$env:CAMPUS_AUTH_PASSWORD = "your-password"
python .\campus_auth.py --config .\config.ini --once --verbose
Remove-Item Env:\CAMPUS_AUTH_PASSWORD
```

也可以使用隐藏输入的一次性认证脚本：

```powershell
powershell -ExecutionPolicy Bypass -File .\run_once_prompt_password.ps1
```

启动桌面设置界面：

```powershell
python .\campus_auth_gui.py
```

如果当前 Python 缺少可用的 Tkinter/Tcl，可以使用只监听本机地址的浏览器设置界面：

```powershell
python .\campus_auth_web.py
```

然后打开终端显示的本地地址，通常为 `http://127.0.0.1:8765/`。
